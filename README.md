## 📌 Executive Summary

This interactive **Financial Dashboard** built in Power BI provides a comprehensive operational and financial performance overview across major platforms and revenue channels, including **Walmart, Amazon, Costco, Uber, Freelance**, and salaried streams. 

The dashboard presents key metrics such as total income, total expenses, net balance, regional transaction distributions, and preferred payment methods in a clear visual layout.
